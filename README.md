# Aphantasia & Mental Imagery

Behavioural and neuroimaging work on visual mental imagery, and on what is missing
when it is absent (aphantasia).

**Status** — a first behavioural round (n = 30) is complete; simultaneous fMRI–EEG
and TMS–EEG are in preparation.

**Data** — not deposited yet. Raw data will be archived on Zenodo/OSF and linked
here with a DOI; this repository will hold the task code (jsPsych), the analysis
code, and lightweight derived tables only.

**Layout** — `src/` analysis and task code · `data/` pointers and checksums ·
`paper/` manuscript material.
